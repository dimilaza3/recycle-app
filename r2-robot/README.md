# R2 Τηλεχειριστήριο

Web εφαρμογή για χειρισμό του εκπαιδευτικού ρομπότ **R2 (Polytech)** μέσω Bluetooth από
λάπτοπ, κινητό ή tablet Android. Δεν χρειάζεται εγκατάσταση: ανοίγει στον browser.

## Πού λειτουργεί

| Συσκευή | Browser | BLE (Bluetooth 4.0+) | Κλασικό Bluetooth (HC-05/06) |
|---|---|---|---|
| Windows / Mac / Chromebook | Chrome, Edge | ✅ | ✅ μέσω «Σειριακή θύρα» (μετά από σύζευξη) |
| Android κινητό / tablet | Chrome | ✅ | ✅ σε νεότερες εκδόσεις Chrome, μέσω «Σειριακή θύρα» |
| Linux | Chrome | ⚠️ ίσως χρειαστεί `chrome://flags/#enable-experimental-web-platform-features` | ✅ |
| iPhone / iPad | Bluefy browser | ✅ | ❌ |

Η σελίδα πρέπει να ανοίγει από **https://** (π.χ. GitHub Pages) ή από `localhost`.
Στο Android μπορείτε να την «Προσθέσετε στην αρχική οθόνη», οπότε ανοίγει σαν εφαρμογή.

## Χρήση

1. Τοποθετήστε τη μονάδα Bluetooth στη θύρα της (κεντραρισμένα, οι δύο ακριανές ακίδες έξω από τη θύρα)
   και ανοίξτε τον **διακόπτη Bluetooth** του ελεγκτή.
2. Βεβαιωθείτε ότι στο ρομπότ είναι φορτωμένο το `code_R2remote` (το ARD:icon το αντικαθιστά,
   βλ. εγχειρίδιο §5.4) ή το LAZ code.
3. Ανοίξτε το ρομπότ. Στο Android ανοίξτε Bluetooth **και Τοποθεσία**.
4. Πατήστε **Σύνδεση με το R2 (BT24)** και διαλέξτε το «BT24». Το ρομπότ παίζει έναν ήχο
   και μπαίνει σε τηλεχειρισμό (όπως με το κουμπί «Send» της εφαρμογής R2).
5. Κρατήστε πατημένα τα βέλη για κίνηση — όταν τα αφήνετε, το ρομπότ σταματά.
   Στο λάπτοπ δουλεύουν και τα βέλη / WASD του πληκτρολογίου.

**Πολλά ρομπότ στην τάξη:** όλα εμφανίζονται ως «BT24». Συνδέετε ένα-ένα (τα υπόλοιπα κλειστά ή ήδη
συνδεδεμένα — ένα συνδεδεμένο ρομπότ δεν εμφανίζεται πια στη λίστα), και κολλήστε ένα αριθμό σε κάθε
ρομπότ και συσκευή.

Αν το ρομπότ δεν εμφανίζεται, τσεκάρετε «Εμφάνιση όλων των συσκευών». Αν η μονάδα σας είναι παλιά HC-06
(κλασικό Bluetooth), κάντε σύζευξη από τις ρυθμίσεις της συσκευής (PIN `1234`) και πατήστε **Σειριακή θύρα**.

## Υλικό R2 (από το εγχειρίδιο Polytech)

| Συσκευή | Θύρα |
|---|---|
| Αισθητήρας υπερήχων | A0 |
| Αισθητήρας γραμμής | A1 |
| LDR | A4 |
| Αισθητήρας ήχου | A6 |
| Αισθητήρας αφής | D11 |
| RGB LED (4 NeoPixel) | D12 |
| Λευκό LED | D9 |
| Βομβητής | ενσωματωμένος (pin 13) |
| Κινητήρες (TB6612) | αριστερός 4/5, δεξιός 7/6 (κατεύθυνση/PWM) |
| Bluetooth | σειριακή 0/1, 9600 baud, με διακόπτη στην πλακέτα |

## Πρωτόκολλο του R2

Το αρχικό πρόγραμμα του R2 (`code_R2remote.ino`) επικοινωνεί στα 9600 baud:

1. Πρώτα περιμένει μια γραμμή JSON: `{"data":[0,0,0,0,0,0,0,0]}` + `\n`.
   Το ρομπότ παίζει έναν ήχο και μπαίνει σε τηλεχειρισμό (~1,5 δευτ.).
   Η εφαρμογή τη στέλνει αυτόματα με τη σύνδεση.
2. Μετά δέχεται εντολές ενός χαρακτήρα:

| Εντολή | Ενέργεια |
|---|---|
| `U` | Μπροστά |
| `D` | Πίσω |
| `L` | Αριστερά (επί τόπου) |
| `R` | Δεξιά (επί τόπου) |
| `S` | Στοπ |
| `T` / `F` | Ήχος 1 / Ήχος 2 |
| `P` | Έξοδος από τον τηλεχειρισμό |

Η κίνηση συνεχίζεται μέχρι να έρθει `S`. Η εφαρμογή στέλνει `S` μόλις αφήσετε το κουμπί.

## LAZ code (πρόγραμμα για το ρομπότ)

Το `arduino/LAZ_code/LAZ_code.ino` αντικαθιστά το `code_R2remote` της Polytech. Φορτώνεται **μία φορά**
σε κάθε ρομπότ (και ξανά αν το ρομπότ προγραμματιστεί με το ARD:icon):

1. Κλείστε τον διακόπτη Bluetooth του ελεγκτή και συνδέστε το ρομπότ με USB.
2. Arduino IDE → ανοίξτε το `LAZ_code.ino` → Tools → Board → **Arduino Uno** → Tools → Port.
3. Πατήστε **Upload**. Χρειάζεται μόνο η βιβλιοθήκη **Adafruit NeoPixel** (υπάρχει στον φάκελο
   «R2_Codes - Libraries» της Polytech).
4. Ανοίξτε ξανά τον διακόπτη Bluetooth.

Με το LAZ code το ρομπότ είναι έτοιμο μόλις ανοίξει και η εφαρμογή το αναγνωρίζει μόνη της.

| Εντολή | Ενέργεια |
|---|---|
| `U` `D` `L` `R` `S` | Μπροστά, πίσω, αριστερά, δεξιά, στοπ (όπως της Polytech) |
| `Q` `E` `Z` `C` | Διαγώνια: μπροστά-αριστερά, μπροστά-δεξιά, πίσω-αριστερά, πίσω-δεξιά |
| `1`–`9` | Ταχύτητα (`3` = όπως της Polytech) |
| `T` / `F` | Ήχος 1 / Ήχος 2 |
| `V` / `v` | Κόρνα on / off |
| `W` / `w` | Λευκό LED (D9) on / off |
| `P` | Παύση τηλεχειρισμού (ξεκινά ξανά με τη γραμμή JSON) |
| `?` | Απαντά `LAZ code v1` |

Παραμένει συμβατό με την εφαρμογή R2 της Polytech (το κουμπί «Send» δουλεύει κανονικά).
Για επαναφορά, ανεβάστε ξανά το `code_R2remote` της Polytech.

## Άλλες εντολές

Στις **Ρυθμίσεις εντολών** μπορείτε να αλλάξετε τι στέλνει κάθε κουμπί. Όσα κουμπιά δεν έχουν εντολή κρύβονται.
Η επιλογή «Επανάληψη όσο πατάς» στέλνει την εντολή ξανά και ξανά όσο κρατάτε το κουμπί,
για προγράμματα που σταματούν το ρομπότ αν δεν λάβουν εντολή.
